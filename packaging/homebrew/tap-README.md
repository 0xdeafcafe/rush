# 0xdeafcafe/homebrew-tap

```sh
brew install --cask 0xdeafcafe/tap/terminal-decline
brew install 0xdeafcafe/tap/rush
```

| | what it is | kind |
| --- | --- | --- |
| [terminal-decline](https://github.com/0xdeafcafe/terminal-decline) | GPU-accelerated terminal emulator (Apple silicon) | cask |
| [rush](https://github.com/0xdeafcafe/rush) | one terminal app to run every coding agent you've got | formula |

homebrew/core has its own `rush` (GNU's restricted shell), so install this
one by its full name, `0xdeafcafe/tap/rush`. Plain `brew install rush` gets
the other one.

Casks and formulae here are updated automatically by each project's release
workflow.
